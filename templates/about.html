How placement predictions work

Student Placement Predictor helps students and placement cells make better decisions with data they already have. This page explains what the system does and where its limits are.

{{ icon('database') }}

1. Learn from outcomes

A model is trained on past student records: CGPA, attendance, four skill scores and experience, together with whether each student was placed.

{{ icon('cpu') }}

2. Compare candidates fairly

Logistic regression, random forest and gradient boosting are compared with cross-validation. The simplest model within half a point of the best is kept.

{{ icon('target') }}

3. Explain the result

Each prediction shows how much every input moved the probability compared with a typical student, so the advice is specific.

What it can and cannot tell you

  • {{ icon('check-circle') }}A probability is an estimate from historical patterns. It is not a guarantee for any student or company.
  • {{ icon('check-circle') }}The bundled dataset is synthetic demo data. Accuracy on your campus depends on retraining with your own placement records.
  • {{ icon('check-circle') }}Company criteria are set by your placement cell and can be changed at any time.
  • {{ icon('check-circle') }}Resumes are stored privately and are only visible to the student who uploaded them.
